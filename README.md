<h1 align="center">Classic Back</h1>

[中文文档](README.zh-CN.md)

Restore classic back gestures for scoped apps (disable predictive back).

## 📥 Installation

Download the APK from the [latest GitHub release](https://github.com/jasongzy/ClassicBack/releases/latest).

- Android 13 or newer
- LSPosed with libxposed API 102 support

Enable in LSPosed, select the target apps in its scope, then completely close and reopen those apps.
